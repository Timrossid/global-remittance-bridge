# Operations Runbooks

This directory contains operational procedures for the Global Remittance Bridge platform.

## Available Runbooks

1. [Incident Response](./incident-response.md) - Step-by-step incident handling
2. [Disaster Recovery](./disaster-recovery.md) - System recovery procedures
3. [Health Checks](./health-checks.md) - Monitoring and health endpoints
4. [Backup and Restore](./backup-restore.md) - Data backup procedures
5. [Deployment](./deployment.md) - Production deployment procedures
6. [Scaling](./scaling.md) - Horizontal and vertical scaling procedures
7. [Security Incidents](./security-incidents.md) - Security breach response
8. [Performance Tuning](./performance-tuning.md) - Performance optimization

## Usage

Each runbook follows a standard format:
- **Overview**: Brief description
- **Prerequisites**: Required tools and access
- **Procedure**: Step-by-step instructions
- **Verification**: How to confirm success
- **Rollback**: How to undo changes
- **Contacts**: Who to notify

## Maintenance

Runbooks should be reviewed and updated quarterly. All team members are expected to contribute to keeping runbooks current and accurate.
